# Supabase Auth email templates (BricksVault-branded)

Generated by `node scripts/build-auth-emails.mjs` — edit the script, not the
HTML, then re-run it. Same dark shell as the alert emails
(`worker/src/lib/alert-email.ts`). Preview: `/mnt/project-files/auth-emails/`.

The `{{ .ConfirmationURL }}`, `{{ .Email }}`, `{{ .NewEmail }}` placeholders are
Supabase template variables; leave them as they are.

## Step 1: Custom SMTP (removes "Supabase Auth" sender and the powered-by footer)

Supabase dashboard → **Authentication → Emails → SMTP Settings** → enable Custom SMTP:

| Field | Value |
|---|---|
| Sender email | `noreply@alerts.bricksvault.app` |
| Sender name | `BricksVault` |
| Host | `smtp.resend.com` |
| Port | `465` |
| Username | `resend` |
| Password | a Resend API key (resend.com → API Keys, "Sending access") |

Then **Authentication → Rate Limits** → emails per hour: `100`.

## Step 2: Paste the templates

**Authentication → Emails → Templates**. For each tab, set the subject, switch
the body to source/HTML, replace everything with the file's contents, Save.

| Tab | Subject | File |
|---|---|---|
| Confirm sign up | Confirm your BricksVault account | `confirmation.html` |
| Invite user | You're invited to BricksVault | `invite.html` |
| Magic Link | Your BricksVault sign-in link | `magic_link.html` |
| Change Email Address | Confirm your new BricksVault email | `email_change.html` |
| Reset Password | Reset your BricksVault password | `recovery.html` |

Subjects are also in `subjects.json`.
